Layihənin əsas problemləri, görülən tədbirlər və sınaq nəticələri

Bu mətn layihənin koduna, avtomatik testlərinə, brauzer yoxlamasına və 40-dan 60 işarəyə genişləndirmə hesabatlarına əsaslanır. Yaxın məsafədə səhv tanımanın qarşısını alan qoruma mövcuddur. Uzunqollu paltarda qolun tanınmamasının tam həll edildiyini təsdiqləyən ayrıca geyim sınağı isə qeydə alınmayıb.

**Kameraya çox yaxın dayanmaq.** Təlim videolarındakı kadrla noutbuk kamerasına yaxın oturan istifadəçinin kadrı arasında fərq vardı. Kodda bu halda modelin yüksək əminliklə səhv işarə verə bildiyi qeyd olunur. Bunun üçün çiyinlər arasındakı məsafənin kadrın hündürlüyünə nisbəti yoxlanılır. Nisbət 0,44-dən böyük olduqda server tanımanı dayandırıb `invalid_pose` cavabı verir. İnterfeys istifadəçiyə geri oturmağı və başdan belə qədər görünməyi bildirir. Çiyinlər görünməyəndə və istifadəçi çox uzaqda olanda da istiqamətləndirici mesaj göstərilir.

`test_signer_too_close_to_the_camera_abstains` testində sintetik görüntü iki dəfə böyüdülüb. Sınaq modeli 99% əminliklə “MƏN” deməyə hazır olsa da, server yaxın kadrı rədd edib; normal kadrda isə tanıma davam edib. Normallaşdırma testləri görüntüdə yerdəyişmə, miqyas və tərəf nisbətinin təsirini də yoxlayır. Bu nəticə yaxın məsafədə düzgün tanımanın təmin edildiyini göstərmir: təsdiqlənən davranış uyğunsuz kadrı qəbul etməmək və istifadəçini yönləndirməkdir. Mənbələr: [API və yaxın məsafə testi](../tests/test_routes_recognise.py), [normallaşdırma testləri](../tests/test_normalize.py), [kamera mesajları](../web/app.js).

**Uzunqollu paltarda qol və əl izlənməsi.** Bu, istifadəçinin bildirdiyi problemdir. Kodda uzunqollu geyim üçün ayrıca öyrədilmiş model, geyimə uyğun düzəliş və ya müxtəlif paltarlarla aparılmış müqayisəli sınaq tapılmadı. Mövcud tədbirlər çiyin və əl nöqtələri itəndə məlumatı idarə etməyə yönəlib: çiyinlərin görünürlüğü zəifdirsə kadr etibarsız sayılır; görünməyən əl üçün ayrıca mövcudluq göstəricisi saxlanılır; əl görünmə payı aşağı olduqda sistem `no_hands` cavabı verir. Bunlar geyimdən yaranan izləmə probleminin tam həlli kimi təqdim edilə bilməz.

`test_low_visibility_or_missing_shoulder_is_invalid`, `test_presence_flags_and_missing_hand_is_zero`, `test_no_hands_gives_hand_ratio_zero` və `test_all_invalid_input_does_not_crash` testləri zəif görünən çiyin, itən əl və tam yararsız giriş hallarını yoxlayır. Bu testlər süni koordinatlarla işləyir; uzunqollu geyimin kamerada düzgün izlənməsini ölçmür. Geyim problemini ayrıca qiymətləndirmək üçün eyni işarələri eyni məsafə və işıqda müxtəlif geyimlərlə yazıb həm nöqtələrin görünmə payını, həm tanıma nəticəsini müqayisə etmək lazımdır. Mənbə: [xüsusiyyət testləri](../tests/test_features.py).

**İşarənin səhv bölünməsi və əllərin qarışması.** Qısa izləmə itkisi bir işarəni iki hissəyə ayıra, ani əl hərəkəti isə işarə kimi qəbul oluna bilər. Mövcud segmentasiya ardıcıl üç başlanğıc kadrı və altı bitmə kadrı gözləyir; 300 millisaniyədən qısa və 4 saniyədən uzun hissələrə ayrıca cavab verir. Sol və sağ əllər detektorun qaytardığı sıraya görə deyil, bədən biləklərinə yaxınlığına görə yerləşdirilir.

Segmentasiya testlərində bir-iki kadr davam edən titrəmə, işarə daxilində qısa fasilə, tək əllə işarə, ardıcıl iki işarə və əllər yuxarıda ikən yazının dayanması yoxlanılıb. Normallaşdırma testlərində əllərin sırası dəyişdirilib və yalnız bir əl qalan hal sınanıb. Bu testlər alqoritmin gözlənilən davranışını təsdiqləyir; real geyim və real kamera sınağını əvəz etmir. Mənbə: [segmentasiya testləri](../tests/test_segment.py).

**Əminliklə verilən səhv sözlər.** “MƏN / MƏNİM / MƏNƏ” və “O / ONUN / ORDA” kimi işarələr arasında qarışıqlıq qalıb. Modelin əminliyi və ən güclü iki namizəd arasındakı fərq yoxlanılır; uyğun şərtlər ödənmədikdə “Əmin deyiləm” cavabı verilir. Bu cavab söz buferinə əlavə olunmur. Əminlik göstəricisi və qərar hədləri yalnız yoxlama dəsti üzərində kalibrlənib.

`test_decide` sərhəd qiymətlərini, zəif əminliyi və yaxın namizədləri yoxlayır; `test_abstain_never_contains_a_word` imtina cavabında işarə adı olmamasını təsdiqləyir. Kalibrləmə testləri hədd seçimi və həddindən artıq əminliyin tənzimlənməsini sınayır. Aktiv 60 işarəli model 1 280 yoxlama klipinin 512-sinə cavab verib: həmin cavabların 491-i düzgün olub, yəni 95,9%. Bununla yanaşı, kliplərin yalnız 40%-nə cavab verilib; imtinasız ümumi dəqiqlik 69,5%-dir. Mənbələr: [qərar testləri](../tests/test_abstain.py), [kalibrləmə testləri](../tests/test_calibrate.py), [model hesabatı](../eval/REPORT.md).

**Kiçik lüğət və söz formaları.** Əvvəl kamera modeli və mətn üçün video xəritəsi 40 sözlə məhdud idi. “Salam”, “necəsiniz” kimi gündəlik ifadələr də problem yaradırdı. Mətn üçün bütün 100 dataset sözünə aid video xəritəsi yaradıldı. “Necəsiniz” mövcud “NECƏ” və “SİZ” işarələrinə ayrılır; dəstəklənən hallar və fel formaları yerli qaydalarla uyğunlaşdırılır. İnkar mənasının itirilməməsi və naməlum sözün başqa sözə səhv çevrilməməsi ayrıca test olunur.

Kamera modeli isə yenidən öyrədilib 40-dan 60 işarəyə artırıldı. İlk namizəddə “BİLMƏK” üçün qəbul olunan üç nümunənin hamısı səhvən “BİLƏR” kimi tanınırdı; “SONRA” üçün isə əminlik həddini keçən nümunə yox idi. Bu iki söz kamera əlavələrindən çıxarılıb “AVTOMOBİL” və “BU HƏFTƏ” ilə əvəzləndi, sonra model yenidən öyrədildi və kalibrləndi. “BİLMƏK” və “SONRA” mətn üçün 100 sözlük video xəritəsində qalır. Son modeldə yeni 20 sinfin hər biri üçün seçilmiş, əvvəlcədən çıxarılmış yoxlama koordinatları həm təcrid olunmuş API-də, həm işləyən yerli serverdə düzgün nəticə verdi. Bu 20 seçilmiş nümunə bütün istifadəçilərdə dəqiqlik ölçüsü deyil.

Söz uyğunlaşdırma və API testləri ilə yanaşı, Chrome yoxlamasında altı ifadənin klipləri səhvsiz oynadılıb; yenidən oynatma, naməlum sözün göstərilməsi və brauzer xətaları yoxlanılıb. Son yerli server yoxlaması 60 tanıma sinfi və 100 video sözü təsdiqləyib. Mənbələr: [söz uyğunlaşdırma testləri](../tests/test_sign_matching.py), [mətn API testləri](../tests/test_text_to_signs.py), [lüğətin genişləndirilməsi](../data/reports/vocab_expansion.md). Əlavə sınaq qeydləri layihə kökündə `tmp/verification/signs-browser-verification.json` və `tmp/recognition60-20261009/{verification,live_verification}.json` fayllarındadır.

**Sınaqların əhatəsi və qalan problemlər.** Son tam avtomatik yoxlamada 266 test keçib. Bunlara koordinatların emalı, segmentasiya, imtina qaydaları, modelin yüklənməsi, lüğətlə modelin uyğunluğu, mətn uyğunlaşdırması və API davranışı daxildir. Həqiqi model üçün xüsusiyyət çıxarışı və tanımanın median müddətinin 50 millisaniyədən az olması da yoxlanılıb. Testlərin keçməsi bütün real kamera şəraitində düzgün tanıma demək deyil.

Uzunqollu geyimlə ayrıca sınaq, yeni istifadəçilər üzərində müstəqil dəqiqlik ölçümü və canlı kamerada geniş yoxlama hələ yoxdur. Yoxlama dəstində təlimdəki işarəçilər də ola bilər. Yeni sözlərdə “AXŞAM” üçün bir səhv qəbul qeydə alınıb; oxşar əvəzliklərdə də qarışıqlıq davam edir. Sistem ayrı-ayrı işarələr üçün qurulub, davamlı işarə dilini və üz ifadələrini tam əhatə etmir. Buna görə nəticələri təqdim edərkən avtomatik testləri, dataset yoxlamasını, seçilmiş API nümunələrini və real istifadəçi sınaqlarını ayrıca göstərmək lazımdır.
