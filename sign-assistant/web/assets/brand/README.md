## Konsept

Axıcı jest simvolu, açıq ovuc formasında neqativ boşluq və danışıq balonunu xatırladan aşağı çıxıntı insan jesti ilə ünsiyyəti birləşdirir. Simvol konkret işarə dili sözünü təsvir etmir.

Mövcud layihə adı saxlanılıb: **AzSL Assistant**. Bənövşəyi və orkide tonları, hərəkəti ifadə edən axıcı forma və sadə tipoqrafiya Azercell-in vizual üslubundan ilhamlanıb.

## İstifadə

Əsas PNG açıq və ya çox açıq bənövşəyi fonda istifadə üçün hazırlanıb. Loqonun nisbətlərini saxlayın; yalnız bir ölçünü məhdudlaşdıranda digər ölçünü avtomatik buraxın.

Veb səhifədə nümunə:

```html
<img
  src="assets/brand/azsl-assistant-logo-v1.png"
  alt="AzSL Assistant"
  width="250"
  height="100"
>
```

Seçilmiş layihə palitrası: bənövşəyi `#65269E`, orkide `#B62B91`, tünd gavalı `#241432`. Bunlar layihə üçün seçilmiş tonlardır, rəsmi Azercell rəng spesifikasiyası deyil.

Bu fayl raster PNG-dir. Hazırlanma üsulu: daxili `image_gen.imagegen` aləti; şəffaf fon rejimi. Orijinal yaradılmış fayl dəyişdirilmədən layihəyə köçürülüb.
