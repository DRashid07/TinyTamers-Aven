# ASAN xidmət — AI ilə ünsiyyət konsepti

[Son şəkil](asan-ai-isare-dili-v2.png) · [Son redaktənin tam promptu](asan-ai-isare-dili-prompt-v2.txt).

Son redaktədə cihaz yığcamlaşdırılıb, əsas ekrandakı avatar tək göstərilib və tərcümənin iki istiqaməti aşağıda ayrı, qarşı istiqamətli oxlarla izah olunub. Əməkdaşın danışması ilə vətəndaşın işarə etməsi vizual olaraq daha aydın ayrılıb.

[İlkin şəkil](asan-ai-isare-dili-v1.png) · [İlkin generasiya promptu](asan-ai-isare-dili-prompt-v1.txt).

İki xanım xidmət masasının əks tərəflərindədir: vətəndaş işarə dili ilə ünsiyyət qurur, əməkdaş danışır. Masa üzərindəki AI assistentin ekranında işarə göstərən avatar var. Şəkildə iki istiqamət işarələnib: “Səs → İşarə dili” və “İşarə dili → Səs”.

Bu, təqdimat üçün yaradılmış konsept səhnəsidir. İnsanlar generasiya edilib. Məkanın ümumi vizual istiqaməti [ASAN xidmətin rəsmi materiallarına](https://asan.gov.az/media/press-releases/zengilanda-doevlet-xidmetleri-merkezinde-asan-xidmet-fealiyyete-baslayib) əsaslanır.

Daxili `image_gen.imagegen` aləti istifadə edilib. Son PNG dəyişdirilmədən layihəyə köçürülüb, mənbə ilə nüsxənin SHA-256 heşləri yoxlanılıb. Əsas şəkil tam fonlu, geniş təqdimat formatındadır.
